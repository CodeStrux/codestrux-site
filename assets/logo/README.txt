CodeStrux Tech logo system
==========================
Symbol: "CST" cube, three flat letters on the faces of an isometric cube, lit from the top.
Wordmark: the name "CodeStrux Tech" in Bruno Ace SC (SIL Open Font License), converted to outlines.

svg/ = vector master, png/ = 2x raster (transparent background unless it is an app icon)
  horizontal-light / -dark        primary lockup. "light" goes on white, "dark" on dark slate or black.
  horizontal-tight-light / -dark  same lockup cropped close, for navbars, headers and footers.
  stacked-light / -dark           for square spaces.
  symbol-light / -dark            the cube alone (document headers, avatars).
  appicon-light / -dark           cube on a rounded tile.
  favicon-light / -dark           simplified cube for 16 to 32 px.
  *-mono-slate / *-mono-white     one colour, no gradients: stamps, embroidery, engraving, one-ink print.

Rules
  Clear space: half the cube's height on every side (built into the files, except "tight").
  Minimum size: horizontal 120 px / 30 mm wide; symbol 24 px / 8 mm. Below 32 px use the favicon files.
  Do not recolour, stretch, rotate, outline or add shadows.

Colours
  Slate #3B4252   Secondary #4B566A   Shading #ECEFF4   Border #D8DEE9   Steel blue #3F6396   Dark ground #262C38
