<p class="eyebrow">Un estudio de dos ingenieros · Cartago, Costa Rica</p>

Somos **CodeStrux Tech** — dos ingenieros que construimos y operamos tanto la
infraestructura como el software que corre encima. Desde el servidor Linux y el
hipervisor hasta la API, el pipeline de datos, la aplicación web y el agente de
IA, lo diseñamos, lo desplegamos y lo mantenemos funcionando.

Trabajamos el stack completo en lugar de una sola capa: Linux y virtualización,
código abierto, nube y serverless, ingeniería de datos, backends y frontends en
Java y TypeScript, facturación electrónica, automatización de mensajería por
WhatsApp y herramientas de IA. Equipo pequeño, colaboración directa y software
hecho para durar.
